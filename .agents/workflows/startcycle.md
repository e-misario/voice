# Workflow: /startcycle

## Descripción
Inicia una nueva iteración de desarrollo en el bucle multiagente:
1. Lee `PLAN.md` y `PROGRESS.md`.
2. Asigna tareas pendientes a los subagentes especializados (`arquitecto`, `backend-dev`, `frontend-dev`, `devops`, `qa`).
3. Ejecuta construcción y validación de componentes.
4. Concluye con actualización de estado y plan para el siguiente ciclo.
